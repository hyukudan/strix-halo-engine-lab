# Native runtime investigation scope

Comparative studies and source-identified external observations are retained privately
outside Git. Public documentation records independent mathematical contracts,
implementation status, project-owned evidence and qualification gates.

The initial target is gfx1151 on Linux with ROCm/HIP. Research lanes include packed
projections, recurrence, sparse attention, model/state residency, phase-specific integer
matrix execution and qualified USBStream transport. No external performance result
qualifies this engine. Do not copy or reconstruct external kernels from observations.

Use the official model semantics, independent oracles and real native replay. Record
adopted dependency provenance and notices accurately. Published ISA/toolchain references
are hardware documentation, not substitutes for native compiler and execution evidence.
