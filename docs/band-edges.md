Generated from the ladder tables by `strix-band-inventory`. Token ranges are inclusive. A band whose lower edge has no timing is listed as EDGE-TIMING PENDING: it keeps its nominal band until device edge timings report and its row sets `narrow_to_floor` (then it starts at its first winning timing point, shown as the measured floor). The lower-edge tolerance is 3 tokens for prompt counts.

The per-request key is produced by `bind_band_receipts` using `LadderArms::over`. It includes the complete execution and reference lever chain, the candidate identity and the tier. Fixed keys appear in full in the [JSON inventory](band-edges.json). An unspecified gate length means the source does not give a prompt length.
