# Native numerical campaign preparation

`lab/native_campaign/numerical/campaign.py` binds an explicitly selected local
GGUF hash to the existing native host tensor auditors, derives actual projection
shapes/storage eligibility and preparation/tile costs, and evaluates pinned
recordings against predetermined mathematical and task/state gates. It never
downloads models, executes HIP or creates a reference baseline.

The closed JSON contracts reject unknown fields, duplicate fields, nonfinite
values, missing prompts, truncated vocabulary/position traces, stale file hashes,
source/runtime/profile substitution and mismatched model/context/history.
Independent teacher-forced logsumexp/KL/NLL and generated-token checks remain
distinct. JSON/tool/context cases compare exact semantic expected objects.
Fresh/resumed state requires all declared persistent classes, actual history
identity and exact within-plan logits/tokens/state bytes. Nested result/reference
logits, state, sources and model pins are rechecked after evaluation.

Q4_0 and IQ4_XS original encodings, scale groups and Wave32 geometry remain
distinct. IQ4_XS uses codebook INT8 operands and rejects K640/raw IU4. Phase
matrices do not authorize cross-phase arithmetic: current integrated integer
selection is C1 eager LM head only. Actual BF16/FP32 activation controls bind
separately to the six default floating LM-head weight formats and exact block
extents. Q4_0 belongs to the experimental integer adapter, not that floating
launcher. W4A16 remains diagnostic/unbound. No integer graph
composition, speculative target substitution or runtime qualification follows.

The opt-in native token decoder RAW recorder and host `raw_import.py` now form a
concrete eager floating, floating graph and experimental integer-head
baseline/result collection path. Actual mode, source activation storage and
emitted numerical descriptor must match the exact selected compiled plan.
Integer selection changes the head only; it does not claim whole-model A4/A8.
Paired teacher-forced
and actual greedy histories remain distinct; final state comes from the greedy
capture, including both convolution allocations. Model/executable/runtime/layout
observations and every nested artifact are checked. Source/compile associations
and external tokenization/decoded text remain explicit pinned operator declarations,
not attestation. Diagnostic costs are unknown rather than invented measurements.

Actual prefix-cache roundtrip recording emits its source checkpoint, restored
checkpoint, full canonical arithmetic lineage and observed mutation position.
The importer checks every component byte, generation, token hash and canonical
identity without fabricating token/chunk rows. Restored graph and eager captures
use distinct explicit history contracts and cannot cross compiled plans. Exact
replay compares actual generation logits as well as teacher-forced logits,
tokens and complete persistent state. Missing restored captures stay unknown;
two fresh duplicates are rejected. The full real-model campaign still requires
all actual prompt/reference recordings, trusted external tokenization/text,
independent fidelity and target execution.
No model, GPU or network campaign was executed. Native operator fixtures and the
independent transport commissioning runbook remain their own first-hardware gates.

The [laboratory runbook](../../../lab/native_campaign/numerical/README.md) specifies
artifact schemas, exact exploratory thresholds, exit codes, private paths,
resource bounds, API entry points and the trusted quiescent file/provenance
limitations. A passed evaluator reports numerical evidence only, never native
execution or model qualification.
