# Experimental exact grouped Q5_1 down probe

This standalone probe evaluates original Q5_1 down weights from already materialized FP32 expert activations. It is available only when `STRIX_ENABLE_EXPERIMENTAL_Q4K_A8_RUNTIME=ON`. It does not add an application flag or alter native dispatch, model weights, activations, residency or semantic output publication. The existing default and native Q4K A8 paths keep their kernel bodies and launch sequences.

The probe places eight output rows in a 256-thread workgroup, one complete wave32 per row. Each lane keeps eight independent original256-thread leaf accumulators. Feature order within each leaf, virtual reduction pairs and ascending expert-slot weighted combination are preserved. The candidate initially retains the original Q5_1 loader and source accumulation expressions. Actual compiler contraction, denormal behavior, reduction order and resource use must be checked before device qualification; host source similarity alone does not establish bitwise parity.

Supported shapes are H=1..2560, I=32..640 in multiples of32, E=1..512 and K=1..min(E,10). Inputs use `intermediates[K][2I]`; only each slot's first I gate/activation values are read. All six views have exact admitted lengths and 16-byte absolute alignment. Mutable status and FP32 accumulation cannot alias any input or weight owner. The public enqueue functions allocate nothing, clear nothing, synchronize nothing and perform no host readback. The caller retains every owner until stream quiescence, including after exceptions. The original receipt requires a positive-zero accumulation seed; the grouped probe overwrites every valid output from its own positive-zero register seed. Both reuse the original ordered route/weight validator and caller-owned sticky status. This standalone probe does not convert scratch into semantic output or implement the native finite-pipeline guard.

The host tests actually execute independent packed Q5_1 decoding, a256-leaf fmaf reference, virtual-tree emulation, seven numerical/packing mutants, signed zero, FP32 subnormals and finite half/coefficient boundaries. GPU fixtures are separate: they compare every accumulator against the CPU oracle and actual original kernel sequence, inspect captured function/launch geometry and K-versus-one down-node count, poison before each replay, exercise invalid routes/weights and sticky status, and check owner canaries. A maximum canonical shape includes E512/H2560/I640/K10; output tails and smaller non-square shapes are also present.

Build target `strix-hip-q51-grouped-down-probe-tests` with HIP and the experimental runtime capability. First compile only and inspect the actual linked gfx1151 object. Device qualification and any later native integration or full-model timing remain separate gates. An exact native extension must match the existing quantized gate/up path's full logits, while its earlier quantization quality assessment remains independently reported. No device, full-model quality or performance result is claimed by this source.
