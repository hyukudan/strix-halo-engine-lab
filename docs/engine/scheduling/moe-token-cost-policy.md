# Observed MoE token schedule

Source candidate, default off. `--moe-token-cost-policy` requires explicit eager generation, D1 and `--moe-shared-overlap` with its existing arena budget. It does not enable or disable prerequisites. Serving, lookup, known windows, RAW/reference, roundtrip, graph and integer-head routes are rejected.

The controller compares the serial-expanded and fork/join schedules on the same retained expanded arena. Kernel arithmetic and catalog selection do not change. It observes complete host-wall input costs through producer completion, output delivery and commit; callback submission time is not GPU execution time. Failed, cancelled, EOS and context-terminal observations are censored. Online cost eligibility never supplies numerical or native qualification. Context identity and position buckets isolate observations; defaults retain the existing fixed fork/join route without policy clocks.
