# Weight plans and image ownership

Home: shared (host shared selection and cache identity; backend core runtime callbacks).

A storage descriptor never chooses numerical arithmetic. Each request names its admitted tensor, arithmetic, backend and incumbent kernel. The resolver checks eligibility before cost and retains the incumbent when no measured decision matches the exact compiler, device and workload. FAST requires explicit permission and a named contract. An image budget failure does not change arithmetic. Operand-exact test permission cannot become a model execution route.

`STRIX_WEIGHT_MEASURED_DECISIONS=0` is the rollback declaration for qualified replacements; family environment readers pass its resolved value through the shared helper. Strategy overrides use the typed request and fail if no eligible qualified registration exists. Missing throughput calibration produces an unavailable cost, never a fabricated prediction. Initial decision tables contain no replacements.

Measured tables use `wfmt.decisions@1` and require a source commit, compiler identity and flags, device, exact shape regime, versioned arithmetic, byte-receipt digest, byte equality and a measured speed result. Registration order breaks ties. Import validates bounded metadata and rejects duplicate or unknown semantic keys. Receipts remain qualification inputs; importing metadata does not establish a device or full-model gate.

The cache reserves image and conversion workspace before work begins. Concurrent identical acquisitions share one conversion. Consumers wait for publication readiness; independent readers do not wait for each other's last-use events. Eviction requires all leases released and all recorded use complete. Content keys include source and sidecar digests, parameter metadata, tensor, slice, strides, shape, format, image, arithmetic, backend, architecture and ABI. A cache belongs to one backend/device. Event failure prevents unsafe eviction; the backend owns deferred retirement without a global device synchronization.

CPU allocation, copy and completion are immediate. Native runtime adapters provide vendor-local primitives with shared retirement mechanics. Uncompiled adapters refuse explicitly. Intel's existing opaque queue has no event publication interface; an event-capable adapter must be supplied before cached images can be used there. No implicit host offload is performed.

Canonical family configuration objects can attach the same `FamilyPlans` result through `attach_weight_plans`. Configuration inspection before tensor admission reports pending plans. It does not invent a tensor index or change incumbent launches. The source migration supplies registrations and loaded maps at the existing shared configuration boundary.

Host checks cover eligibility, exact decision regimes, malformed imports, concurrent publication, budget and event failures, sidecar invalidation, deferred retirement, and CLI/serve plan parity through the GLM shared resolver. Existing numerical paths remain the comparison baseline.
