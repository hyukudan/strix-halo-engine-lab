## Inkling full-model comparison

1. Run each backend's reference and candidate with the same checkpoint, token IDs, `--profile exact`, prefill chunk and greedy generation length. Run a one-row append, a multi-row prompt and a prompt that crosses the sliding-cache boundary. Compare complete emitted IDs and `--logits FILE` bytes.
2. Run both binaries separately with `--gate-manifest MANIFEST --gate-out OUT --gate-arm REF --gate-rows N --gate-mode prefill --profile exact`, and repeat in decode mode. Compare corresponding FP32 dumps and route captures byte for byte. Use separate output directories. The gate script's ticket checks require a single binary per output directory.
3. On HIP repeat with `--packed-decode` and `--grouped-decode` separately. Inspect the saved stage histories, KV bytes and controller/residual fixtures across chunk boundaries. Preserve the reference plan, BF16 arithmetic and token capacity within each comparison.
4. Read registers, spills, occupancy and instruction streams and run the no-model fixtures before the full-model checks. Record hardware and power state, kernel and active IOMMU PerfOpt when collecting timings.
