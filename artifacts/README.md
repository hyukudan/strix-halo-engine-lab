# Artefactos de investigación

Estos JSON contienen únicamente resúmenes agregados y anonimizados generados
por las herramientas de `../tools/`. No contienen cuerpos, firmas completas,
parámetros template ni desensamblado de kernels.

- `halogen-metadata-{0,1,2}.json`: recuento y recursos declarados por objeto.
- `halogen-isa-q4moe.json`: mezcla ISA agregada de las variantes MoE Q4.
- `halogen-isa-deltanet.json`: mezcla ISA agregada de variantes DeltaNet scan.
- `halogen-isa-attention.json`: mezcla ISA agregada de variantes de atención.

La fuente es la imagen OCI y el binario fijados en `../RESEARCH.md`.
