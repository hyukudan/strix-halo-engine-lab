# Project artifacts

This directory retains approved project/model metadata. Source-identified external
runtime inspection artifacts are private and excluded from the working repository.

The pinned official model configuration is a geometry reference, not native execution
qualification. Preserve applicable model provenance and license requirements.

The retained [official configuration](qwen-official-config-de4b8e4.json) supplies
shape references used by [memory planning](../MEMORY_BUDGET.md). Its source
revision and applicable terms are recorded in the [source ledger](../SOURCES_LEDGER.md).
Models, private host inventories and benchmark result directories do not belong
in this artifact directory.
